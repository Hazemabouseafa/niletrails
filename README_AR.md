# NileTrails Atelier — UI/UX v2

نسخة تصميم تفاعلية جديدة لـ NileTrails، مطورة من البداية اعتمادًا على اللوجو الأصلي المرفق، وباتجاه بصري Travel Editorial يجمع الأزرق النيلي، الأبيض العاجي، والذهبي الهادئ.

## الملفات المهمة
- `index.html`, `styles.css`, `app.js`: نموذج الواجهة التفاعلية Responsive، بدون أي مكتبات JavaScript خارجية.
- `assets/`: لوجو العميل الأصلي بعد تقليل الهوامش + 3 صور مفاهيمية عالية الدقة مولدة بالذكاء الاصطناعي للاستخدام في التصميم فقط.
- `previews/`: لقطات Desktop وMobile لكل قوالب الصفحات الأساسية، بالإضافة إلى لوحات نظرة عامة.
- `docs/ANTIGRAVITY_MASTER_PROMPT.md`: برومبت مفصّل لبناء الموقع التجاري النهائي.
- `docs/UX_DESIGN_SYSTEM.md`: القواعد البصرية والتفاعلية.
- `docs/SITEMAP_CONTENT_MODEL.md`: خريطة الصفحات والمحتوى والبيانات والفلاتر.
- `docs/QA_RELEASE_CHECKLIST.md`: معايير اختبار وتسليم المشروع.

## التشغيل
1. فك الضغط.
2. افتح `index.html` في المتصفح؛ التطبيق يستخدم hash routes لكي يعمل كنموذج Static.
3. عند استخدام سيرفر محلي من داخل مجلد المشروع: `python -m http.server 8080` ثم افتح `http://localhost:8080`.
4. مثال صفحة: `http://localhost:8080/#/nile-cruises`.
5. افتح صور `previews/` للمقارنة البصرية قبل وبعد تنفيذ Antigravity.

## مهم قبل التسليم للعميل
- التصميم **Prototype**، وليس Booking Engine حقيقيًا أو موقعًا منشورًا.
- جميع الصور الثلاث المستخدمة داخل الصفحات صور **AI concept imagery**؛ استبدلها بصور حقيقية مصرح باستخدامها وتطابق القوارب والوجهات المعروضة. الصورة غير دليل على وجود قارب أو معبد بهذا التكوين.
- عناصر الكروز والدهبية هي *نماذج بيانات توضيحية* وليست أسماء سفن أو أسعار أو توافرًا مؤكدًا.
- نموذج الاستفسار يتحقق من الحقول فقط ولا يرسل ولا يحفظ بيانات على سيرفر.
- لم تُضف أرقام هواتف أو عناوين أو أسعار أو تقييمات أو شهادات أو تراخيص غير مؤكدة.
- نسخة الإطلاق تحتاج الصور والبيانات المعتمدة، الترجمة إذا طلبها العميل، النصوص القانونية، سياسة الخصوصية، تكامل نموذج التواصل، نظام إدارة المحتوى، والاستضافة والاختبارات النهائية.
